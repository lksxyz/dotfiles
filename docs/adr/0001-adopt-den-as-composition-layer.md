# Adopt Den as the home configuration composition layer

The dotfiles repo previously wired a single standalone home-manager config by hand (`homeManagerConfiguration` + `extraSpecialArgs` + path imports). We adopted Den (`denful/den`) as the composition layer: the flake now evaluates via `mkFlake` + `import-tree`, modules are per-concern `den.aspects.*` units, and `den.homes.x86_64-linux.lukisxyz` produces the same `flake.homeConfigurations.lukisxyz` output. We chose Den over staying with plain flake-parts modules or migrating to `flake-parts` + `nixosConfigurations` because the repo owns no NixOS host, the standalone-home surface is Den's supported "standalone home" case, and per-concern aspects give cross-platform reuse if a Darwin/NixOS host is ever added. The prior `extraSpecialArgs` (php72, nixGL) became `inputs` closure references inside aspect modules; sops-nix is imported per-aspect via `inputs.sops-nix.homeManagerModules.sops`.
